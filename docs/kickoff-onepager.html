CHT UI Builder — Squad Kickoff

v0.1 shipped · Squad meeting prep

A no-code editor that lets non-developers author, maintain, and deploy CHT app configurations — without touching XLSForm cell syntax, tasks.js, or the cht CLI.

Need

Every CHT deployment needs a developer in the loop. Adding a survey question, inserting a hierarchy level, or shipping a follow-up task is engineering work — even when the change is operationally trivial. This bottlenecks CHT scaling to the long tail of district, NGO, and MoH deployments.

If a district health officer can change Excel, they should be able to change a CHT config.

Vision & Mission

Vision (12–18 mo): Every CHT consultancy partner and Medic deployment can hand a project folder to a non-developer who can keep it healthy unattended — and deploy from the same tool.

Mission: A local-first editor that operates on real cht-conf folders, preserves everything it doesn’t touch byte-for-byte, surfaces every “decision” the system makes for clinician sign-off, and ships through cht-conf with friendly errors.

MVP scope

In already shipped

  • Edit existing forms (survey, choices, settings, properties, translations)
  • Hierarchy editor with topological derivation + insert/reorder
  • Task editor (priority, appliesIf, events, actions builders)
  • Contact-summary context flags editor
  • Decisions (sign-off) aggregated view
  • Deploy: macros + friendly errors + dry-run + 4 templates
  • Undo across all editors + sticky chrome
